# คู่มือลงบทความ CREATR365 (ระบบใหม่)

## หลักการ (เหมือนที่เว็บบทความทั่วโลกทำ)
เก็บ "เนื้อหา" แยกจาก "หน้าตา" — เนื้อหาของแต่ละบทความเป็นข้อมูลล้วน ๆ ส่วนหน้าตา (ปกดำ, สารบัญ, ตาราง, สถิติ ฯลฯ) มีแม่แบบเดียวอยู่ในเว็บ
ทุกบทความจึงสวยเหมือนกัน และถ้าอยากปรับดีไซน์ ก็แก้แม่แบบที่เดียว บทความเก่าทั้งหมดเปลี่ยนตาม

## ทุกครั้งที่มีบทความใหม่ (ไม่ต้องแก้โค้ดอีก)
1. ให้ Claude Design (หรือ Claude ธรรมดา) สร้างบทความ โดยใช้ข้อความ "คำสั่งสำเร็จรูป" ด้านล่าง
2. ไฟล์ที่ต้องเอา = ไฟล์เนื้อหา `articles/ชื่อบทความ.js` ในโปรเจกต์ (เปิดด้วย Notepad ได้ คัดลอกข้อความทั้งหมด)
   - ไม่ต้องใช้ ZIP, ไม่ต้องใช้ Standalone HTML, ไม่ต้องใช้ PDF
3. Admin › จัดการเนื้อหา › บทความ › สร้างใหม่ › วางทั้งหมดในช่อง "เนื้อหาเต็ม (HTML)"
   - ระบบแปลงให้อัตโนมัติ ใต้ช่องจะขึ้นสถานะ "บทความแบบโครงสร้าง · N บท · M บล็อก"
   - ถ้ามีข้อมูลขาด (เช่น ไม่มีรูปปก) จะขึ้นคำเตือนสีเหลือง
4. กด Preview ดู แล้วบันทึก

## HTML ต่างจาก PDF อย่างไร
PDF = รูปถ่ายของหน้ากระดาษ ลิงก์/ขนาดตัวอักษร/มือถือใช้ไม่สะดวก ค้นหาใน Google ได้ไม่ดี
HTML/เนื้อหาโครงสร้าง = หน้าเว็บจริง ปรับตามจอ กดลิงก์ได้ ค้นหาได้ — ใช้อันนี้สำหรับบทความ

## คำสั่งสำเร็จรูป (คัดลอกไปวางใน Claude Design)
> สร้างบทความเรื่อง "<หัวข้อ>" ด้วยเทมเพลต Creatr365 Article แล้วบันทึกเนื้อหาเป็นไฟล์ articles/<ชื่อ>.js
> กติกา: ใส่ `meta.heroImage` และ `src` ของทุกบล็อก image เป็นลิงก์ https เต็มเท่านั้น (ห้ามใช้ slot) ถ้าไม่มีรูปให้ละบล็อก image นั้นไปเลย อย่าสร้างลิงก์ขึ้นเอง
> ทุกข้อมูลตัวเลข/แหล่งอ้างอิงต้องมีที่มาจริง ถ้าไม่มี ให้บอกว่าไม่มี

## ข้อจำกัดที่ยังไม่ได้ทดสอบ
- รูปจาก imagekit และฟอนต์ Google (เครื่องที่ทดสอบออกเน็ตภายนอกไม่ได้ จึงใช้รูปจำลอง)
- บันทึกลง Supabase จริง / เปิดใน LINE in-app browser
- ไฟล์ .js ที่มีลูปไม่รู้จบ (while(true)) จะทำให้แท็บค้าง — ไฟล์ปกติจาก Claude ไม่เป็น
- บทความ HTML เดิม (PR #56) ใช้ต่อได้เหมือนเดิม ไม่ถูกแตะ

## สถานะงาน (22 ต.ค. 2569)
